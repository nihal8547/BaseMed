# BaseMed - Premium Medical Supplies in Qatar

BaseMed is a comprehensive web platform for Qatar's trusted supplier of premium medical, dental, and CSSD materials. It empowers clinics, hospitals, and dental practices with high-quality supplies, exceptional service, and timely delivery. Built with modern web technologies for blazing-fast performance and an excellent user experience.

## Technologies Used

- **Framework**: [Nuxt 3](https://nuxt.com/) (Vue.js)
- **Styling**: Custom CSS with an intuitive design system
- **Icons**: [Lucide Vue](https://lucide.dev/)
- **SEO & Sitemaps**: `@nuxtjs/sitemap` & `@nuxtjs/robots`
- **Backend**: Nuxt Nitro for API routing and file handling

## Setup & Installation

Make sure to install the dependencies:

```bash
# npm
npm install

# yarn
yarn install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
npm run dev
```

## Production Build

Build the application for production:

```bash
npm run build
```

Locally preview the production build:

```bash
npm run preview
```

Check out the [Nuxt deployment documentation](https://nuxt.com/docs/getting-started/deployment) for more information on hosting.
